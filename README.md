# くびふうせん（Neck Balloon）

**肩こりストレッチなのに、首で風船を運ぶゲームみたい。** iPhone を机に立て、首をゆっくり倒す・うなずく・見上げる・横を向く・回す動きが、そのまま風船（自分の頭）の操作になる。雲の輪に届いて 3 秒保つと（設定の「判定のゆるさ」が「ゆるめ」のとき。「ふつう」は 4 秒）輪が満ちる。**速く動かすと風が乱れて点が減り、ゆっくり大きく伸ばして保つほど高得点**（ストレッチとして正しい動きに報酬を合わせる）。

- だれの：デスクワークで首と肩が固まる 20〜40 代。ストレッチは退屈で 3 秒で終わらせてしまう人
- どう使う：今日の 1 分（コースは日ごとに変わる）→ 結果（点数・首の動いた範囲の分度器）→ 記録（続けた日・暦・範囲の移り変わり）
- 入力：前面カメラ（TrueDepth があれば ARKit の顔の追跡、なければ Vision の顔の向き）／iPhone を両手で持って傾ける（CoreMotion）／指でなぞる。**映像は保存も送信もしない**（フレームから角度だけを取り出して捨てる）
- 作らなかったもの：姿勢の常時監視、映像の保存、HealthKit、オンラインのランキング、医療の約束（「治る」「改善」と書かない）、Apple Intelligence

監督の指示：daily-ideas #13（題材は監督が決めた）。今日の記録：daily-ideas #14。

## 世界観（2026-11-16 に作り直し：絵本の水彩の空）
- 棚卸し：風船・ひも・雲・空の時間帯・太陽と月・星・遠い丘・分度器・ストレッチの到達点・ゆっくりの風・首の角度・1 分
- **このアプリでは、風船が自分の頭に、水彩の雲の輪がストレッチの到達点に、空の時間帯（朝焼け・昼の青・夕暮れ・夜と星）がコースに、紙に描いた分度器の扇形が首の動いた範囲になる。** どれも自作の Shape / Canvas（`App/Sources/UI/World.swift`）
- **空の時間帯で画面全体の色が大きく変わる**：今日のコースの空が、ホーム・記録・コース・設定の地になる（朝焼けの橙と薔薇色・昼の青と緑の丘・夕暮れの紫と夕陽・夜の藍と三日月と星）。プレイと結果はそのコースの空。Pro の画面は夜と星。オンボーディングは 1 ページごとに朝焼け → 昼 → 夕暮れと空が移る
- 色：空ごとに 1 組（`SkyPalette`：上・中・地平線の 3 色、地平線の光、雲、雲の影、丘 2 層、太陽、紙の上の洗い色 3 段階）。どの空でも同じなのは、水彩紙（`#FBF4E8`）・藍のインク（`#2B2948`）・風船の朱（`#F08B72`／濃い `#D45F4C`）・金（満ちる輪と太陽 `#F7CB72`）
- 地：濃い空（上は `#0D1334`〜`#3A78C6`）。中身は空に置いた水彩紙のパネル（辺が少し波打ち、縁に空の色がにじむ）に、藍のインクで書く
- 書体：見出しも数字も本文も丸い字（`.rounded`、見出しは heavy）。絵本の字
- 主役の部品：絵本の風船（逆さのしずくの形、水彩の朱、にじんだ光、手描きの 2 重の輪郭、ねむった顔とほお。保っている間はほほえむ）、水彩の雲の輪（にじんだ雲のつぶ、下に絵の具がたまる、満ちる線は金）
- 動き：雲は場面ごとに少しずれるだけで、動き続けない。静かで気持ちいいを保つ
- 音：オルゴールの音（A のペンタトニック）。失敗は低い音ではなく、ふっと吹く風の音
- ほかの 6 本との違い：色の系統（空の時間帯で変わる濃い空と朱）・地の明るさ（暗い〜濃い地）・見出しの書体（丸い字の heavy。ほかは明朝）・主役の部品の形（水彩の風船と雲）の 4 つとも違う
- 参考の UI：**Alto's Odyssey**（時間帯で空の色の組がまるごと変わる・遠い丘を層で重ねて奥行きを出す・遊びの画面は文字を最小に）と **Headspace**（丸い太い字・やわらかい丸い形・紙のような温かい地）。借りたもの：①時間帯で画面全体の色の組を変える ②空の下に 2 層の遠い丘 ③丸い太い字と、角の大きなやわらかい紙。キャラ・絵・ロゴ・名前は借りない

## 手応えの表（feel.md）
| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | 朱のボタンが 0.96 倍に縮む（spring 0.3 / 0.65） | selection | なし（静かに） |
| 輪に入った | 雲の輪が 1.08 倍にふくらんで戻る（0.4 秒）、的の光が強まり、風船のほおが色づく | soft 0.6 | オルゴールの A5 ひとつ |
| 保つ | 輪の金の線が満ちていく（にじんだ光つき）、風船がほほえむ、「そのまま 3→1」 | なし | なし |
| 1 つ終えた | 輪の外へ金の波紋が広がって消える（0.7 秒） | light 0.8 | E6 → A6（星がひとつ灯る） |
| 速すぎた（失敗） | 風船が左右に揺れる、案内が朱の「ゆっくり。風が乱れています」 | warning（2 秒に 1 回まで） | ふっと吹く風の音（やわらかいノイズ） |
| コースを終えた | 満ちた雲の輪の中で点数が 0 から数え上がる（0.9 秒）、金の言葉、紙に分度器 | success | 星が降るように下りる 5 音 |
| 場面の切れ目 | 数え 3・2・1（水彩紙の丸の上）、終わりは easeOut 0.3 のフェード。オンボーディングは空が 0.5 秒で移る | なし | 始まりに D6 の短い音 |

動きを減らす設定では、ふくらみ・波紋・揺れ・数え上げを止める。オンボーディングの見本は 2 回くり返したら止まる（動き続ける画面を作らない。右上の黒い丸の件）。

## 毎日開く理由（depth.md）
1. 今日の 1 分：コースが日ごとに変わる（無料は 8 コースを順に、Pro は 24 コースから）
2. 続けた日と、この 7 日の小さな風船の並び（途切れても「おかえりなさい」）
3. 首の動いた範囲（左右・上下・向き）の分度器。先週・はじめの日と比べて広がりが見える
4. 毎日のお知らせ（無料）、仕事中の 1 時間ごとの 1 分（Pro）
5. 共有カード（点数・風の言葉・分度器。顔や映像は入れない）

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）
1. ホーム：今日の空（コース「はじめの空」は朝焼け）と、数週間分の見本の記録（2.5 秒）
2. プレイ：首を右に倒すと風船が雲の輪へ流れ、3 秒保つと輪が満ちて次の「左に倒す」へ（13 秒）
3. 結果：点数が数え上がり、首の動いた範囲の分度器が描かれる

## 安全と審査
- 最初に「痛いときは、すぐにやめてください」。角度は「小さめ」から。医療の約束をしない（審査 1.4.1）。角度は「めやす」と書く
- カメラの映像は保存も送信もしない。ARKit の顔の追跡で得るのは頭の向き（角度）だけで、端末の外に出さない（審査 5.1.2(vi)、PRIVACY.md に明記）

## 開発
- 処理は画面から切り離し（`App/Sources/Engine/`：向き・コース・採点・記録・決まった動き）、`Tests/` に振る舞いのテスト（Swift Testing）
- 顔の向きを出す所は `HeadPoseSource`（カメラ・傾け・指・決まった動き）。CI のシミュレータではカメラが使えないので、テストと撮影は `ScriptedMotion`（お手本の動き）で動かす
- 撮影：起動引数 `-screenshotScene <名前>`（home・play・result・courses・records・settings・pro・permission・onboarding、`en-` を付けると英語）
- iPhone Duo：size class で並べ替え（内側の画面ではプレイの右に「いまの首の向き」の線の顔と次の動き、ホームと結果は 2 列）
